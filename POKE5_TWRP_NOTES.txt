BOOX Poke5 initial TWRP device tree notes

Status: first-pass source tree built and boot-tested. Recovery ADB works, but initial UI repeatedly restarted due to DRM modeset/pageflip errors.

Firmware used for extraction:
- 2024-06-05_12-04_3.5.1_19ed122a7
- Android 11 / API 30
- Kernel 4.19.157
- Current slot during extraction: _a

Important partition sizes:
- boot_a / boot_b: 100663296 bytes
- recovery_a / recovery_b: 100663296 bytes
- dtbo_a: 25165824 bytes
- vbmeta_a: 65536 bytes
- super: 4294967296 bytes
- metadata: 16777216 bytes

Display notes:
- Resolution: 1072x1448
- Density: 300
- Android primary display orientation: ORIENTATION_270
- Touch input: fts_ts, ABS_MT_POSITION_X max 1072, ABS_MT_POSITION_Y max 1448
- Poke5 exposes Qualcomm DRM/KGSL nodes, not i.MX EPDC framebuffer nodes.
- Kindle i.MX EPDC TWRP patches are not directly portable. Only borrow the high-contrast monochrome theme strategy and no-blank/no-timeout behavior.
- Initial TWRP build reached recovery ADB (`ro.twrp.boot=1`) but UI restarted repeatedly. `/tmp/recovery.log` showed `drmModeSetCrtc failed ret=-22` and `drmModePageFlip failed ret=-16`.
- `patches/0001-poke5-drm-debug-nonfatal-pageflip.patch` is a device-tree-contained patch file that must be applied from the TWRP source root before building. It still modifies `bootable/recovery/minuitwrp/graphics_drm.cpp` in the build tree, but the patch itself is tracked here.

Known likely first build issues:
- Prebuilt kernel was extracted by magiskboot as raw ARM64 Image although stock recovery reports KERNEL_FMT gzip. If the built image fails to boot, preserve/repack the original compressed kernel payload instead of using this raw Image.
- FBE v2 / metadata encryption may not decrypt /data on the first build.
- Dynamic super partitions may need fastbootd tuning.
- Rotation/touch mapping must be tested on device.
- Brightness/frontlight paths need testing: panel0-backlight, panel1-backlight, onyx_bl_br, onyx_bl_ct.

Recommended first test target:
- Build recoveryimage.
- Do not flash both recovery slots.
- Test only recovery_a first, keep recovery_b stock.
- Keep EDL recovery path and stock recovery_a backup available.
